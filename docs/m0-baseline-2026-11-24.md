### Reproduce the read-only snapshot

Run in PowerShell on the Windows machine that will be used for development.
This reads repository/package/display status. It does not fetch, switch,
install, create/remove displays, start/stop the keeper or inject faults.
It examines the interpreter selected by the current shell; a missing package
is useful evidence, not a reason to install or switch environments automatically.

```powershell
$vmRepo = 'C:\dev\virtumon'
"Computer: $env:COMPUTERNAME"
git -C $vmRepo --no-optional-locks status --short --branch
git -C $vmRepo rev-parse HEAD
git -C $vmRepo log -1 --format='%h %cI %s'
Get-Command python, virtumon -ErrorAction SilentlyContinue |
    Select-Object Name, Source
$vmPython = (Get-Command python -ErrorAction Stop).Source
& $vmPython -c "import sys, virtumon; print('Python:', sys.executable); print('Module:', virtumon.__file__)"
if ($LASTEXITCODE -eq 0) {
    & $vmPython -m virtumon --version
    & $vmPython -m virtumon doctor
    & $vmPython -m virtumon list --json
    & $vmPython -m virtumon list --managed --json
    & $vmPython -m virtumon agent status --json
}
```
